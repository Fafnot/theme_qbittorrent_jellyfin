verloren skin for qBittorrent (all stock features, new look)
1. Copy this folder to the server and run:   ./install.sh /srv/.../qbittorrent/verloren qbittorrent
   (it downloads the stock WebUI matching your qBittorrent version and applies the skin)
2. Compose volume:   - /srv/.../qbittorrent/verloren:/verloren:ro   then Down/Up the stack
3. qBittorrent -> Options -> Web UI -> Use alternative Web UI -> /verloren   (Ctrl+F5)
To roll back: untick the option.
